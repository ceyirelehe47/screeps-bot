# OH 作为 HUB 专用储备

本轮将 OH 加入默认储备名单，与原有十种 T3 共用单品储备目标。线上当前 HUB 为 E4N58，目标为 20,000 OH；其他房间不设 5,000 OH 的常规储备目标。正在执行反应所需的单批 OH 属于生产原料，继续保留。

## 行为

- 旧五种/十种 T3 默认名单自动迁移加入 OH；自定义部分名单保留原选择。没有硬编码运行时 HUB 房间名。
- 不足时优先从其他房间可用 OH 导入，扣除当前反应与已有供料承诺，仅补 HUB 缺口，并扣除健康在途覆盖。HUB 达标后不继续集中外房的全部 OH。
- 普通房间不会收到 `hub:export:OH` 常规储备补给，卫星库存缺口计算与进度展示中的 OH 外房缺口均为零。
- OH 生产目标不叠加卫星 T3 补库量；外房 OH 不会被当作 HUB 已达标。
- OH 兼作反应原料：按“储备目标 + 下游消耗”统一扣库存，达到储备时发生 T3 消耗仍会安排补充。本 tick 新建的补货也纳入覆盖，避免 fallback 再生产同一份库存。
- 沿用当前 Hub committed protection 的库存保护口径，将 OH 的绝对目标限定于 HUB；外房只保留真实生产需求。没有切换 Treasury 或市场写入开关。
- 面板储备区从 T3 Reserve 改为 Reserve，原进度字段兼容保留。
