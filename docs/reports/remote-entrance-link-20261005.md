## 实现

- 从外矿任务与 roadPlan 的实际边界点识别回程入口。使用实际房内路径长度与能省下的通行距离决定建设，不用直线坐标距离否定绕行场景。
- 沿真实回程道路末段，选择邻近可站立道路、偏离道路本体的 link 位置。避开地形墙、现有结构/工地、其它规划结构、源矿和控制器；保留原规划中尚未建造的仓库、源矿与控制器 link 额度。只使用空闲额度，不拆现有结构。
- 将位置追加到现有 link 规划，并在 layout 的 `remote_entry_link` 标记中记录业务角色；现有建造调度执行节流、工地上限和建造。重复规划复用同一位置，不重复新增。
- 建成的入口 link 作为发送端，优先送到仓库接收 link。本地源矿发送 link 保持原有控制器优先策略。
- remoteMiningCarrier 在母房选择实际有效的入口 link 卸能量；短暂满载或发送冷却时保持目标；已在旁边的成员清除旧移动意图，停留等待发送清空后继续卸载，不改跑 storage。接收网络不可用、仓库满或母房正在防御时使用原有仓库/terminal 回退。
- 普通 carrier 优先释放接收端达到半容量后的背压，排在后台供给之前；强化任务、紧急 lab 清理和关键能源补给保留更高优先级。取能、预约、房内移动与归仓沿用现有系统；同 tick 接受 withdraw 后等下一帧 Store 更新，防止重复领取。

此变更不补 spawn 能量，不改 Treasury 或市场写入配置。构建、类型检查和测试仅在 dsh 隔离目录执行。
