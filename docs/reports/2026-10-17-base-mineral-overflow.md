# 基础矿物出口与战争洞口修复

设计来源为 2026-10-17 基础矿物协调方案，原基线 `545113e9`。运行验收资料保存在忽略目录 `monitor-data/20261017-base-mineral-overflow/`。

## 运行时分层（2026.10.17-5）

每房每矿物使用当前完整保护账本。生产、Boost/War、工厂、Hub、内部调拨、在途和已挂 exposure 继续保护；市场在 ResourceControl 之后运行，内部生产优先级和 terminal 仲裁保持有效。

- 正常区：保护量以外不超过 30000，沿用签名底价与冷却。
- 溢出区：超过上述阈值，连续授权 lane 使用 100 tick 间隔；底价向可信新鲜买价 EMA 的 0.6 倍靠拢，保留逐 lane 每日最多 15% 下移限制。EMA 过期时沿用正常底价。
- 清仓区：保护量以外超过 80000，或 storage 低于现有容量压力阈值；在 terminal 原生冷却和 WAL 允许时继续出售。价格必须覆盖交易能量影子成本，并至少获得每单位 1 credit 的净收益；部分成交最坏成本校验仍有效。
- 每笔仍是 1000，单 pending、两次完整读取、历史 permit、额度与仲裁均保留。原 R2 单次受控试验独立保留；常态分层无需外部心跳，不沿用过期试验控制租约。
- 未得到 continuous 写授权的 lane 只记录分层，不因库存高而自动签发交易权限。生产保护或终端证据缺失时禁止出售。

停采只用于连续五次已授权、终端可用的清仓报价评估都找不到可执行买单，或 storage 承压。暂停原因和次数记录于 `Memory.runtime.baseMineralOverflow`；恢复要求库存降到溢出线以下。未获权限、CPU/证据不足和资源未进入 terminal 都是等待，不累计无买单次数。

## 战争移动

开放寻路预算为每次 8000 ops。完整开放路径直接交给共享交通层，每 tick 重验下一步物理可达与耗塔安全许可，不再调用另一套 `findPathTo` 重搜。己方非搭档与敌方实体使用 0xfe 动态代价。预算耗尽后继续有界突破搜索，只有完整路径中的屏障才允许攻击。普通移动统一拒绝终点没有进入目标 range 的半截路径。

耗塔双人组的安全区限制继续生效；突破搜索找到墙不代表允许进入墙后的危险区。

## 安全缓冲迁移

2026.10.17-6 单独调整签名 policy：默认安全缓冲改为 inventoryReferenceAmount × 2，H/X 为 16000，其余基础矿物为 10000；实际生产需求仍由账本每次动态叠加。当前没有可靠的逐矿物实际消耗率历史，因此使用设计规定的默认缓冲，不把库存净变动误当作生产消耗率。

迁移白名单只接受明确旧 revision 与 laneReserve=100000，并逐字段核对其余策略；保留 lane 身份、continuous/review 证据、WAL receipt head 与额度历史。部署后顺序为更新 canonical cfg（r8 与新 forecastBuffer）、提出策略迁移、签收同一提案，再核对原 continuous lane 仍可写。失败时恢复发布前配置及完整模块，禁止直接清空许可链或倒退 WAL。若新许可已经签收，回滚旧代码后市场保守停卖，保留最新许可与成交历史供修复版恢复；不能用发布前 Memory 覆盖已经发生的成交。

所有测试、构建和完整回归在服务器隔离目录执行。最终发布由干净 main 提交构建，并核对 origin/main、完整模块读回、实际 shard1 执行身份和有界健康窗口。


## 新房间兼容修复（2026.10.17-7）

实服迁移发现 E3N54 在旧 permit 签收后新增了 7 条 shadow lane：当前 scope 为 63 条，旧 active grant 仅 56 条。旧迁移只重签历史 grant，因覆盖数不一致被完整校验拒绝，许可与 WAL 未改动。修复后仅为缺失的 shadow+suspended lane 补齐 suspended grant；未签名却已晋级的 lane 仍拒绝迁移，不授予新房间交易权限。已有 continuous/review 与成交历史照旧保留。


## PowerBank 发现目录与生产承诺（2026.10.17-8）

实服的未准入 discovered 记录没有来源房间和 tier，旧保护适配器将它们一律记为 Boost 源不完整，导致已授权市场通道长期停卖。仅排除拥有合法任务 ID/目标房间、sourceRoom 为空串且 tier 未设置的规范发现记录。PowerBank 准入先检查成品 Boost 的本地、在途或供给房库存，再同步写入来源和 tier 并进入 preparing_boosts，因此发现目录不代表原矿生产承诺。已准入任务和已分配 Boost lab 仍独立完整保护；半填、未知来源、损坏任务继续阻止出售。

开放与突破矩阵叠加动态实体时取原代价与 0xfe 的较大值，保留敌方 rampart 等 0xff 硬障碍；双角色执行顺序均补了占据 rampart 的敌方 PowerCreep 与真实洞口集成回归。
