## 本次候选的处理

完整开放目录 API 保留本帧 fresh 语义。新增纯几何候选供 Observer 与 Scout 使用；实际选定观察或巡逻目标时再校验本帧状态。覆盖证明逐个检查未被几何覆盖的房间是否开放，并要求至少一个开放的覆盖见证；全关闭目录不能自证全覆盖。

Scout 保存目标身份，每 tick 校验当前目标；到达、危险、关闭、失效或移出候选后才重选。旧 filtered-index 仅在迁移时读取一次完整目录，不能直接当几何索引。来源并集无开放房时仍允许稳定原点回退；全关闭时等待。未选房重新开放不打断正在进行的合法巡逻。

普通观察的 500 tick 冷却以最近成功观察为准；非到期房中途关闭再开放不会清除该冷却。显式任务复看依旧独立。`runtime.powerBankObserver.coveredRooms` 现表示几何覆盖，可能包含关闭房，仅作诊断，实际许可不读取该 Memory 列表。

测距缓存和 PathFinder 原因此前缺少命中证据。本候选仅附加与既有 CPU profiler 同步的有界诊断：区分 ready/pending 命中、确证过期、worldKey 变化、实际淘汰、真实新测量、预算等待及三段搜索的 incomplete/非法路径/异常。无 entry 统一记 unknown miss，不能伪称因 LRU 或输入变化失效。诊断最多保留 32 个目标/来源房间对，不保存完整 key 或路径；不改变 TTL、配额、安全门和业务返回。

## 验证口径

旧 v4 的 Observer 回归已正常执行到断言：冷却帧期望零次调度状态读取，实际读取 117 次；Scout 的两项回归分别复现目标单房读取期望 1 次、实际 117 次，以及未选房重新开放引起目标身份改变。三例均无类型、API 或运行时错误，不把 selector 排除项当作掉例。

最终候选执行完整 PowerBank 域及受影响 CPU 模块回归、两组类型检查和 clean detached 构建；该验证范围与 v4 的 258 模块全量执行分别标记。原始结果、源与产物指纹、上传回读及实际 console 保存在忽略目录 `monitor-data/20261015-powerbank-lazy-v5/` 的冻结证据中。发布前后采样须按实际部署 tick 分隔，单独报告窗口和启动成本；查询次数合同不能替代实际 CPU 收益。

## v5 实况与剩余重试

v5 提交 `a0a933aa77c146be49d8704b53d5e24375b6671d` 经服务器 25 个完整模块、305 个用例及双类型检查、构建通过。2026-10-15 12:46 UTC 上传回读成功，模块 SHA256 为 `ebc4308be7a0d6ceb546edb2a3d25e96e017ee68b8c0f338ef14610dcaf8974f`；实际 shard1 console 确认部署 tick `74350637`。本地及远端 main 随后正常快进至此提交。

v5 的 17 点 warm 窗口 `74350647–74350759` 中，Observer 平均 2.381 CPU，全目录 openStatus 阶段为 0；相比上述 v4 的 7.408，确实减少了该热点。当前 flush 平均 103.659、启动平均 6.861，最大 flush 133.069，bucket 从部署前 5606、冷启动后 5202 回升至 6869。负载不同，不能把总量变化全部归因于目录修复；health 最后未完成 tick 仍为旧 `74347984`。

同版独立诊断窗口 `74350640–74350752` 的 17 个有请求采样帧记录 265 次测距请求：234 次 invalid_input；17 次真实战斗路径搜索均 incomplete、各耗尽 6000 ops，其中 14 次已有失败 entry 明确过期。主要重复来源为 E6N59 到 E10N54、E10N55、E10N57。该窗口与 CPU warm 窗口相邻但不完全相同，不能按每 tick 或简单乘采样间隔外推次数。

路径输入上限是 16 房，但来源路线生成没有同一上限。E6N59、E4N58、E1N57 到 E14N50 的最短四方向路线分别至少含 18、19、21 房，必然不受支持。E10N51 的无效输入不能仅凭统计归为长路线，须单独保留具体计数。

本轮在资源、Lab 和逐 Spawn 测量前挡下不支持的路线。128 项否定 LRU 以 shard、worldSize、来源、目标和当前危险集合为 key，保守再查为 100 tick；全部来源等待时保留 discovered 任务。不能直接失败删除，否则 Observer 下一次发现会立即重建同一任务。其它无效输入停止同源剩余 Spawn 检查，仍保留 5 tick 等待；有完整证据的其它来源可以照常准入。

实际 engineIncomplete 也仅表示本算法本次未取得完整路径。同输入保守等待 100 tick，复用时仍校验当前状态与 world key，改变后允许重新测量；这不作为“无路”或任何投入许可。预算、余量、坏路径和异常等暂态保留原短退避。等待期间生命周期绝对截止检查仍先执行；全部来源等待时，新来源或地图变化最多保守延后至 100 tick 再查，不宣称任务立即唤醒。成功缓存、原生 6000 ops 上限和每 tick 测量配额保持。

新增多 tick 回归覆盖 Observer 再发现同一银行仍保留一个任务、100 tick 内不重复昂贵评估、到期与绝对截止、危险/世界输入改变、其它可行来源准入，以及三个任务乘三个 Spawn 的工作集能够遍历完。Observer 夹具曾把 task.id 与 bankId 设成不同值，独立审查在执行前发现该偏差；已统一原生身份并逐帧断言单一任务，旧夹具未作为业务红灯。
