## Why

出征任务能持续造兵，但目标优先级和换代决策缺乏战果反馈。玩家需要知道小队为何推进、为何停手，以及下一轮会采取什么行动。

## What Changes

- 以目标房间的当前情报驱动侦察、集结、攻坚、控制器压制与清场确认。
- 根据能开火的塔、目标耐久和距离选择攻击目标，沿用现有可达性和耗塔撤退约束。
- 双人行军共用路径和过房点，覆盖掉队、狭道拥堵及边界重聚。
- 双人队在换代前比较战果，连续受挫后重新评估入口或停止重复投入；通过已有状态命令展示决定。

## Capabilities

### New Capabilities

- `war-campaign-command` 统筹出征决策、攻坚目标及战果反馈。

### Modified Capabilities

- `war-workflow-lifecycle-ownership` 可重复任务的换代增加基于战果的停止条件。

## Impact

涉及 War 运行时、近战角色、任务 Memory 与状态快照。现有控制台入口、共享队伍、巡逻和出生调度继续使用。
