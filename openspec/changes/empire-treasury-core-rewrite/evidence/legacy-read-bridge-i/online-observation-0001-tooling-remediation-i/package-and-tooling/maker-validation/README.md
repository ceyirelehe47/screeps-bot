# 本包验证范围

`final-tests.tap`为最终版本100项Node测试原始结果；对应命令、stderr与退出码分开保存。`mutations.json`记录五种临时副本故障均被测试检出，没有改动交付工具。

回环HTTP和WebSocket测试运行了实际本地服务器；CLI测试执行新脚本与恢复子进程，但用明确的test preload替换仓库检查／客户端目标／凭据入口。没有使用实际游戏token，没有向screeps.com发请求。进程终止只针对本测试自己创建的Node子进程；Windows及真正服务端尚未验证。

`references/deployGuard.cjs`是从已读取的固定源码提取的两个函数，供本地离线对照；正式工具从真实候选仓库按完整Git blob核对再加载。本环境的Git访问确实失败，故没有将摘录测试说成完整候选验证。`candidate-boundary.cjs --repo ...`由Agent必跑，不能skip。

开发期间一次语法检查发现缺少函数闭括号，已在开始协议测试前修正；当前全部工具语法检查通过。其余阶段性测试均用于本地开发，不冒充最终源码的正式结果。

本包不包含实际采样、上传或恢复的成功材料。最终样本和实际代码身份必须由Agent在授权内取得。
