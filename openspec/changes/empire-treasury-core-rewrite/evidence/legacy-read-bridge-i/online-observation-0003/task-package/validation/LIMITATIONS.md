# 制作方验证边界

制作环境：Linux、Node v22.16.0。固定测试通过不等于正式观察已通过。

已执行：92项Node固定测试；真实临时Git仓库中的配置关闭与限定路径恢复；真实loopback HTTP传输；独立Node collector/恢复工作进程/父监督器组成的模拟正式运行；补丁镜像check/apply与逐字节重构；全部CJS语法检查；最终ZIP解压后的精确文件集合与同一测试入口复验。

模拟进程测试使用fake WebSocket与工作目录中的模拟服务器状态，保留真实子进程边界和一次性标记/恢复逻辑，但压缩采样与尾部确认的等待时间。原始日志验证器测试用冻结读取器形状的构造报告。它们不是私服Screeps引擎、官方服或真实75秒计时实验。禁止将这些结果改称为实机采样成功。

未执行：原生Windows/NTFS实测；真实用户仓库195 suites/685 tests；真实Rollup全仓编译；对用户现有token的扫描；官方服身份/模块前检、候选上传、真实12点采样、恢复与75秒确认。这些由Agent的固定入口在任何code POST之前/之后按任务书产生原始证据。

没有从该容器连接Screeps、读取真实token或发送任何官方服code POST。GitHub源码/元数据读取只是制包的依据，不是一次官方服观察。

进程独立、固定窗口、有限等待与排他marker不能覆盖主机断电、全进程被强杀、永久磁盘/网络故障。恢复不确认时保留ONLINE_CLOSE_UNCONFIRMED；不能把请求已受理等同恢复已核对。

采样器预算是合作式检查，不可能从最终样本日志读到其自身输出后的成本。正式成功口径保留前11点可归属全成本与最后一点不可观测，不修改生产代码补测。账号CPU频道并不自带shard字段；与shard1 console及代码回读组合证据，不误称CPU帧自身证明某shard。

本包的成功合同不保证现实世界legacy表一定齐全；缺失、损坏、超界、不匹配等真实问题必须以INCONCLUSIVE收尾，而非篡改数据或放宽阈值。
